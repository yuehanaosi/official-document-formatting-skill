# 公文版式与交付核查 | Layout & Preflight

## 一、通用版式核查

以 GB/T 9704—2012 第5、7、8、10章为定位依据。以下参数用于通用正式发文版式，具体项目按标准对应条款和已确认模板处理。

| 位置 | 核查项 |
| --- | --- |
| 纸张与版心 | A4（210 × 297 mm）；上白边37 mm、左白边28 mm，两者允许偏差±1 mm；版心156 × 225 mm。按标称尺寸推导右26 mm、下35 mm。通常每面22行、每行28字。Word 行距需结合网格、字宽和实际渲染校验。 |
| 版头 | 已确认的发文机关标志、发文字号及需要时标注的份号、密级、紧急程度、签发人；发文字号的年份使用六角括号，顺序号无“第”且不补零。上行文的发文字号与最后一个签发人姓名同行，发文字号左空一字、签发人右空一字。 |
| 主标题 | 通用版式位于红线下空二行，一般用2号小标宋（22 pt）居中。多行按词组切分，参考梯形或菱形排列，保持机关名称、书名和关键事项完整。 |
| 主送和正文 | 主送在标题下空一行，顶格并用全角冒号收尾。首页显示正文，主送过多时核对是否移至版记。正文通常3号仿宋（16 pt），首行空二字。四级序号依次为“一、”“（一）”“1.”“（1）”，各层常用黑体、楷体、仿宋、仿宋。 |
| 附件和落款 | 附件说明在正文下空一行、左空二字，多件依序编号，名称末尾不加标点。附件另面，核对名称、序号及一起装订时的连续页码。成文日期用完整阿拉伯数字年月日，月日不补零。按是否用印、是否联合行文套用对应署名和日期规则。 |
| 版记与页码 | 核对主送移列、抄送、印发机关和印发日期及版记底线位置。通用页码位于版心外，一般用4号（14 pt）半角宋体数字，两侧一字线，奇数页右空一字、偶数页左空一字。版记页前有空白页时，两页均不编页码。 |

## 二、选择式样

- 信函格式按第10.1条核对发文机关标志、红色双线、第一条双线下的发文字号、首页页码和版记。文种“函”与所选版式分别核对。
- 命令（令）按第10.2条核对机关标志、令号、签名章及日期。纪要按第10.3条及单位式样核对标志与出席、请假、列席名单。
- 内部材料、工作方案、汇报稿、附件表格采用有依据的单位模板或适合阅读的版式。横排表格和特定语种文件核对适用规则、装订方向与实际字体。
- 文号、签发人、密级、印章、日期等按真实状态处理。草稿需预留时用明确占位，未经确认的印章或签名不得补画。

## 三、Word/WPS 编辑与验收

1. 先检查节、页边距、页面网格、奇偶页页脚、自动编号、表格及附件分页。仅改版式时使用命名样式、真实缩进和分页控制，避免逐段敲空格或连续插空行。对需保留的编号和域检查自动更新结果。
2. 检查中文字体映射及运行环境。字体缺失时标注替换及其对行宽、分页的影响，交付前以可用的 Word/WPS 或渲染器检查版面。无法渲染时把尺寸检查与待完成的页面检查写清楚。
3. 对比原件与副本的文本和结构。检查长标题断行、首页正文、孤行与跨页表格、署名及日期、版记、附件目录及连续页码。版式审校与文件的审批、用印、签发属于不同流程。
