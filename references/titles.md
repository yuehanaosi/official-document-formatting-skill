# 公文、材料与电子文件标题 | Titles, Headings & Filenames

## 一、先判断行文目的

按《党政机关公文处理工作条例》第八、九、十五条核对文种和标题。正式公文标题以发文机关名称、事由和文种为基础，并核对令、公报、公告、通告等特定式样。先核实隶属关系、职责、行文对象和预期办理结果，再写事由。以下方括号字段供替换。

| 场景 | 标题示例 | 判断依据 |
| --- | --- | --- |
| 办理部署 | [发文机关]关于开展档案目录核查工作的通知 | 有执行事项及受文对象 |
| 印发本机关制订的方案 | [发文机关]关于印发《档案目录核查工作方案》的通知 | 核对文件归属和附件全名 |
| 批转下级机关文件 | [发文机关]批转[报送机关]《[文件名称]》的通知 | 具备批转关系并以实际文件名为准 |
| 转发已有文件 | [发文机关]转发[原发文机关]关于开展档案目录核查工作有关文件的通知 | 引用具体文件时用核准题名，避免叠加多层“关于”和“通知” |
| 请求上级批准 | [发文机关]关于增设档案服务窗口的请示 | 一文一事，写明所请事项 |
| 向上级汇报 | [发文机关]关于档案服务窗口运行情况的报告 | 报告中不得夹带请示事项 |
| 答复下级请示 | [发文机关]关于同意增设档案服务窗口的批复 | “同意”须符合实际审批结果 |
| 商洽或协助 | [发文机关]关于协助核对档案目录的函 | 平行或不相隶属机关，复函核对来函事项 |
| 特定范围周知 | [发文机关]关于档案查阅窗口临时调整的通告 | 核对周知范围、日期及权限 |
| 记录会议议定事项 | [会议名称]纪要 | 采用经确认的会议名称和期次 |
| 提出处理办法 | [发文机关]关于规范档案移交流程的意见 | 正文须体现意见或处理办法 |

决议、决定、命令（令）、公报、公告和议案还应按条例第八条核实发布主体、程序和适用场景。遇到“申请报告”“请示函”等混用，检查真实行文关系后再确定文种。引用独立文件题名时按适用的标点规则使用书名号，避免机械套用“标题一律无标点”。发文字号、时间、拟稿阶段和稿件版本通常另作标注。

## 二、内部材料和章节题写法

- 方案写清任务及实施范围，如“档案目录核查工作方案”。分期推进时，可用“摸清存量并建立清单”“逐卷比对和问题复核”“交接清单及成果验收”。
- 汇报、总结写出对象和观察期间，如“第一季度档案移交工作情况”。可按“移交进度”“尚未移交的档案及原因”“后续办理安排”组织。
- 调研报告围绕问题和调查范围，如“基层档案查阅服务运行情况调研报告”。可按“服务现状”“窗口访问与调阅障碍”“可调整的办理环节”组织。
- 项目材料可用“[项目名称]阶段验收情况报告”“[会议名称]会议议程”“[事项]核查问题清单”。按流程、主题、责任或问题编排章节，同层标题保持语法和概括尺度协调。使用“核对、清点、补录、复核、报送、移交”等能落实到具体对象的动词。

## 三、电子文件名和英文标题

电子文件名服务于检索和版本管理。按单位归档规则命名。无既定规则时可用 `日期_事项或简称_版本.扩展名`，如 `20261119_档案目录核查工作通知_送审稿.docx`。日期和状态按事实填写，避免路径保留字符、重复扩展名和个人敏感信息。正式归档所需元数据按归档规定维护。

英文标题使用已核准的机关译名，保持事项和办理动作一致，区分 Notice、Report、Request for Approval、Official Reply 等语义。以下译文为工作示例：

- 档案目录核查工作方案 / Work Plan for Verifying Archival Inventories
- 关于增设档案服务窗口的请示 / Request for Approval to Open an Additional Archives Service Counter
- 档案移交情况报告 / Report on the Transfer of Archival Records
